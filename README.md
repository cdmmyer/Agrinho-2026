## 🌎 Sobre o Projeto

O **Água que Alimenta** é uma aplicação web desenvolvida para o Concurso Agrinho 2026.

O projeto apresenta informações sobre o uso consciente da água na agricultura e mostra como práticas sustentáveis podem ajudar a equilibrar a produção agrícola com a preservação do meio ambiente.

A proposta está diretamente relacionada ao tema oficial:

> **"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente."**

A ideia principal é mostrar que cuidar dos recursos naturais também é uma forma de garantir que a agricultura continue produzindo alimentos no futuro.

---

## 🎯 Objetivo

O objetivo do projeto é conscientizar sobre a importância do uso responsável da água na agricultura.

Além disso, o projeto procura mostrar que tecnologia, planejamento e educação ambiental podem contribuir para uma produção agrícola mais sustentável.

---

## 🌱 Problema Abordado

A agricultura depende da água para diversas atividades. Porém, o desperdício, o uso inadequado da irrigação, vazamentos e a falta de planejamento podem aumentar o consumo desse recurso.

Outro desafio é a necessidade de preservar rios, nascentes e outras áreas importantes para a conservação dos recursos hídricos.

Por isso, é importante buscar maneiras de produzir alimentos utilizando a água de forma eficiente e responsável.

---

## 💡 Soluções Apresentadas

O site apresenta algumas práticas que podem contribuir para o uso consciente da água:

- 💧 Irrigação eficiente;
- 🌱 Monitoramento da umidade do solo;
- 🌦️ Observação das condições climáticas;
- 🌳 Proteção de nascentes;
- 🚜 Planejamento da produção;
- ♻️ Redução do desperdício;
- 📚 Educação ambiental.

---

## ⚙️ Funcionalidades

O projeto possui diferentes recursos interativos:

### 💧 Calculadora de economia de água

O usuário informa uma quantidade de água utilizada diariamente e escolhe uma porcentagem de economia.

A aplicação calcula uma estimativa da quantidade de litros que poderia ser economizada.

### 🧠 Quiz de sustentabilidade

O site possui um quiz com perguntas sobre:

- Uso consciente da água;
- Agricultura sustentável;
- Preservação ambiental;
- Irrigação;
- Recursos hídricos.

A pontuação é calculada automaticamente pelo JavaScript.

### 📱 Design responsivo

O site foi desenvolvido para funcionar em:

- Computadores;
- Notebooks;
- Tablets;
- Celulares.

## 🚀 Publicação no GitHub Pages

Para publicar o projeto:

1. Abra o repositório `agrinho2026`.
2. Acesse **Settings**.
3. Clique em **Pages**.
4. Em **Source**, escolha **Deploy from a branch**.
5. Selecione a branch **main**.
6. Selecione a pasta **/root**.
7. Clique em **Save**.
8. Aguarde o GitHub publicar o site.
9. Copie o endereço gerado.
10. Coloque o endereço no campo **Website** do About.
11. Coloque o mesmo endereço neste README.
